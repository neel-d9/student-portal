# Student Portal
## Overview
A Student Portal Web App for managing courses, grades, attendance and mess bookings.
## Requirements
- Node.js >= 18
- npm >= 9
## Installation
```bash
git clone https://github.com/neel-d9/student-portal.git
cd student-portal
npm install
```
## Running the App
```bash
npm start
```
The aoo runs on http://localhost:3000 by default.
